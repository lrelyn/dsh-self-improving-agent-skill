# Self-Improving Agent

Follow the protocol in [AGENTS.md](AGENTS.md) for every task in this project.

Key points:
- Read `AGENT_MEMORY.md` before starting a task; append an entry after finishing.
- Judge results objectively (exit codes, files, tests) instead of a subjective "looks done".
- Verify before claiming completion.

If `AGENT_MEMORY.md` does not exist, create it in the project root.
